# Система онлайн-записи и информационный портал медицинской клиники

## Общее описание
Данный проект представляет собой полнофункциональный веб-сайт для медицинской организации. Система совмещает в себе информационный портал и интерактивный сервис для онлайн-записи на прием с автоматизированным контролем доступности временных слотов.

## Структура веб-сайта
Сайт включает в себя следующие разделы:
* **Главная страница:** Общая информация и быстрый переход к записи.
* **О нас:** История клиники, информация о квалификации врачей и лицензиях.
* **Новости:** Лента актуальных событий, акций и медицинских статей.
* **Пациентам:** Справочная информация, правила подготовки к обследованиям и внутренний распорядок.
* **Услуги:** Форма для получения анализов (в разработке).
* **Анализы:** Каталог лабораторных исследований и диагностических процедур.
* **Личный кабинет:** Персональный раздел для пациентов и врачей с управлением графиком посещений.

## Ключевые технические функции
* **Контроль доступности:** Алгоритм генерации свободных окон для записи, исключающий накладки в расписании.
* **Ролевая модель:** Разграничение интерфейса и прав доступа для пациентов и медицинского персонала.
* **Динамический каталог:** Управление списком услуг, врачей и новостей через административную панель.
* **Адаптивность:** Корректное отображение всех информационных и функциональных страниц на любых устройствах.

## Стек технологий

### Бэкенд
* Python 3.10+
* Django 5.0+
* Django REST Framework
* SimpleJWT (авторизация на базе токенов)
* PostgreSQL / SQLite

### Фронтенд
* Next.js 14+
* React 18+
* TypeScript
* Ant Design (UI-компоненты)
* Axios / Day.js

## Архитектура проекта
Проект организован по модульному принципу:
* **Информационные модули:** Реализованы в виде отдельных маршрутов на фронтенде, данные для которых подтягиваются через API.
* **Модуль записи:** Ядро системы, обеспечивающее синхронизацию между БД и пользовательским календарем.
* **Уровень безопасности:** Все транзакции и личные данные защищены проверкой JWT-токенов на серверной стороне.

## Инструкция по установке

### Бэкенд
1. Перейдите в папку бэкенда: `cd backend`
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости: `pip install -r requirements.txt`
4. Выполните миграции: `python manage.py migrate`
5. Запустите сервер: `python manage.py runserver`

### Фронтенд
1. Перейдите в папку фронтенда: `cd frontend`
2. Установите пакеты: `npm install`
3. Запустите среду разработки: `npm run dev`
